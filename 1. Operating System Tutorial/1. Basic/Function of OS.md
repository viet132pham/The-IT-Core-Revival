# Functions of Operating System

## 1. Process Management
- The OS manages processes by scheduling and coordinating execution.
- It handles process creation, termination, and inter-process communication.
- Example: In Windows Task Manager, users can see running processes and end tasks.

## 2. Memory Management
- The OS allocates and deallocates memory as needed by different programs.
- Virtual memory techniques are used to optimize usage.
- Example: Swapping in Linux allows running large applications with limited RAM.

## 3. File System Management
- Manages storage, retrieval, and organization of data in files.
- Ensures security and access control mechanisms.
- Example: NTFS in Windows and ext4 in Linux handle file organization.

## 4. Device Management
- OS communicates with hardware via device drivers.
- Manages input/output devices efficiently.
- Example: Plugging in a USB drive, the OS detects and allows access to files.

## 5. Security and Access Control
- Ensures user authentication and permission handling.
- Prevents unauthorized access using encryption and firewalls.
- Example: Linux uses permissions (read, write, execute) to control access.

## 6. User Interface
- Provides an interface (GUI or CLI) for user interaction.
- Example: Windows has a graphical user interface (GUI), while Linux offers CLI.

## 7. Networking
- Enables communication between systems over a network.
- Supports protocols like TCP/IP, HTTP, and FTP.
- Example: Browsing the web involves OS managing network connections.

## 8. Error Detection and Handling
- Detects hardware and software errors, ensuring system stability.
- Example: Windows "Blue Screen of Death" alerts users to system failures.

# Chức năng của Hệ điều hành

## 1. Quản lý tiến trình
- Hệ điều hành quản lý các tiến trình bằng cách lập lịch và phối hợp thực thi.
- Xử lý việc tạo, kết thúc tiến trình và giao tiếp giữa các tiến trình.
- Ví dụ: Trong Task Manager của Windows, người dùng có thể xem và dừng các tiến trình đang chạy.

## 2. Quản lý bộ nhớ
- Hệ điều hành cấp phát và thu hồi bộ nhớ khi các chương trình yêu cầu.
- Sử dụng bộ nhớ ảo để tối ưu hóa hiệu suất.
- Ví dụ: Tính năng "swapping" trong Linux giúp chạy ứng dụng lớn với bộ nhớ RAM hạn chế.

## 3. Quản lý hệ thống tệp
- Quản lý việc lưu trữ, truy xuất và tổ chức dữ liệu trong tệp.
- Đảm bảo bảo mật và quyền truy cập dữ liệu.
- Ví dụ: NTFS trên Windows và ext4 trên Linux giúp tổ chức tệp hiệu quả.

## 4. Quản lý thiết bị
- Hệ điều hành giao tiếp với phần cứng thông qua trình điều khiển thiết bị.
- Quản lý các thiết bị nhập/xuất một cách hiệu quả.
- Ví dụ: Khi cắm USB, hệ điều hành phát hiện và cho phép truy cập tệp tin.

## 5. Bảo mật và kiểm soát truy cập
- Đảm bảo xác thực người dùng và quản lý quyền truy cập.
- Ngăn chặn truy cập trái phép bằng mã hóa và tường lửa.
- Ví dụ: Linux sử dụng quyền (đọc, ghi, thực thi) để kiểm soát quyền truy cập.

## 6. Giao diện người dùng
- Cung cấp giao diện (GUI hoặc CLI) để người dùng tương tác.
- Ví dụ: Windows có giao diện đồ họa (GUI), trong khi Linux cung cấp dòng lệnh (CLI).

## 7. Mạng
- Hỗ trợ giao tiếp giữa các hệ thống qua mạng.
- Hỗ trợ các giao thức như TCP/IP, HTTP và FTP.
- Ví dụ: Khi duyệt web, hệ điều hành quản lý kết nối mạng.

## 8. Phát hiện và xử lý lỗi
- Phát hiện lỗi phần cứng và phần mềm để đảm bảo hệ thống ổn định.
- Ví dụ: "Màn hình xanh chết chóc" trên Windows cảnh báo lỗi hệ thống.
