# Application Layer

## Definition
The Application Layer (Layer 7) is the topmost layer of the OSI model. It provides network services directly to end users and facilitates communication between applications over a network.

## Example
When you browse a website using a web browser, the Application Layer enables the retrieval and display of the webpage through HTTP/HTTPS.

---

## Client-Server Model

### Definition
The Client-Server Model is a network architecture where client devices request services from centralized servers.

### Example
When you use Google Search, your browser (client) sends a request to Google's servers, which process the request and return the search results.

### Key Features
- Clients initiate communication, while servers provide requested resources.
- Uses specific protocols like HTTP, FTP, and SMTP.
- Supports scalability by allowing multiple clients to access the same server.

---

## World Wide Web (WWW)

### Definition
The World Wide Web (WWW) is a system of interlinked documents and resources accessed via the internet using web browsers.

### Example
When you visit a website like Wikipedia, your browser retrieves and displays content using HTTP/HTTPS.

### Components
- **Web Browsers**: Software used to access websites (e.g., Chrome, Firefox).
- **Web Servers**: Store and deliver web pages to users (e.g., Apache, Nginx).
- **HyperText Markup Language (HTML)**: Standard language for creating web pages.

---

## E-Mail

### Definition
E-Mail (Electronic Mail) is a method of exchanging messages electronically over a network.

### Example
When you send an email using Gmail, it is transmitted via SMTP and retrieved using IMAP or POP3.

### Protocols Used
- **SMTP (Simple Mail Transfer Protocol)**: Used to send emails.
- **IMAP (Internet Message Access Protocol)**: Allows access to emails on a remote mail server.
- **POP3 (Post Office Protocol 3)**: Downloads emails to a local device.

---

## Content Distribution Network (CDN)

### Definition
A Content Distribution Network (CDN) is a network of servers that cache and deliver web content to users based on their geographic location.

### Example
Netflix uses CDNs to deliver video content efficiently, reducing buffering times.

### Benefits
- Reduces latency by serving content from a nearby server.
- Improves website load times and performance.
- Enhances security by mitigating DDoS attacks.

---

# Tầng Ứng Dụng

## Định nghĩa
Tầng Ứng Dụng (Lớp 7) là lớp cao nhất trong mô hình OSI, cung cấp các dịch vụ mạng trực tiếp cho người dùng cuối và hỗ trợ giao tiếp giữa các ứng dụng qua mạng.

## Ví dụ
Khi bạn duyệt web bằng trình duyệt, tầng Ứng Dụng cho phép truy xuất và hiển thị trang web thông qua HTTP/HTTPS.

---

## Mô hình Máy khách - Máy chủ

### Định nghĩa
Mô hình Máy khách - Máy chủ là kiến trúc mạng trong đó thiết bị máy khách yêu cầu dịch vụ từ các máy chủ tập trung.

### Ví dụ
Khi bạn tìm kiếm trên Google, trình duyệt (máy khách) gửi yêu cầu đến máy chủ Google, xử lý yêu cầu và trả về kết quả tìm kiếm.

### Đặc điểm chính
- Máy khách khởi tạo giao tiếp, máy chủ cung cấp tài nguyên.
- Sử dụng các giao thức như HTTP, FTP, SMTP.
- Hỗ trợ mở rộng với nhiều máy khách truy cập cùng một máy chủ.

---

## World Wide Web (WWW)

### Định nghĩa
World Wide Web (WWW) là hệ thống tài liệu và tài nguyên liên kết với nhau, được truy cập qua internet bằng trình duyệt web.

### Ví dụ
Khi bạn truy cập Wikipedia, trình duyệt sẽ lấy và hiển thị nội dung trang web bằng HTTP/HTTPS.

### Thành phần
- **Trình duyệt web**: Phần mềm truy cập trang web (Chrome, Firefox).
- **Máy chủ web**: Lưu trữ và cung cấp trang web (Apache, Nginx).
- **HTML**: Ngôn ngữ chuẩn tạo trang web.

---

## E-Mail

### Định nghĩa
E-Mail (Thư điện tử) là phương thức trao đổi tin nhắn qua mạng.

### Ví dụ
Khi bạn gửi email qua Gmail, email được truyền qua SMTP và truy xuất bằng IMAP hoặc POP3.

### Giao thức sử dụng
- **SMTP**: Gửi email.
- **IMAP**: Truy cập email trên máy chủ từ xa.
- **POP3**: Tải email về thiết bị cục bộ.

---

## Mạng Phân Phối Nội Dung (CDN)

### Định nghĩa
Mạng Phân Phối Nội Dung (CDN) là hệ thống máy chủ lưu trữ và phân phối nội dung web theo vị trí địa lý của người dùng.

### Ví dụ
Netflix sử dụng CDN để truyền tải nội dung video hiệu quả, giảm thời gian tải.

### Lợi ích
- Giảm độ trễ bằng cách phân phối nội dung từ máy chủ gần nhất.
- Cải thiện tốc độ tải trang web.
- Tăng cường bảo mật, giảm tấn công DDoS.
