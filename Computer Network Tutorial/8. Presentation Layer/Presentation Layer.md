
# Session Layer and Presentation Layer

## Presentation Layer

### Definition
The Presentation Layer (Layer 6) is responsible for translating, encrypting, and compressing data so that it can be understood by the Application Layer and transmitted efficiently over the network.

### Example
When you visit a secure website (HTTPS), the Presentation Layer encrypts your data using SSL/TLS before transmission.

### Services Provided by Presentation Layer
- **Data Translation**: Converts data into a format that can be understood by the receiving application.
- **Encryption and Decryption**: Secures data by encrypting it before transmission and decrypting it upon receipt.
- **Compression and Decompression**: Reduces the size of data for faster transmission.

---

## Protocols in Session and Presentation Layers

### Application Filing Protocol (AFP)
- Used in Apple networks for file sharing and resource access.
- Example: AFP enables Mac computers to share files over a network.

### NetWare Core Protocol (NCP)
- Used in Novell NetWare operating systems for client-server communication.
- Example: Enables file and printer sharing in NetWare networks.

### Secure Socket Layer (SSL)
- Provides encrypted communication for secure internet transactions.
- Example: HTTPS websites use SSL for secure login and data transfer.

### Remote Procedure Call (RPC)
- Allows programs to execute procedures on remote systems as if they were local.
- Example: Microsoft Windows uses RPC for network service management.

### Point-to-Point Tunneling Protocol (PPTP)
- Used to implement Virtual Private Networks (VPNs).
- Example: Employees use PPTP-based VPNs to access company resources remotely.

### Multipurpose Internet Mail Extensions (MIME)
- Defines email content types, supporting attachments like images, audio, and video.
- Example: Gmail uses MIME to send and receive multimedia email attachments.

# Tầng Phiên và Tầng Trình Diễn

## Tầng Trình Diễn

### Định nghĩa
Tầng Trình Diễn (Lớp 6) chịu trách nhiệm dịch, mã hóa và nén dữ liệu để nó có thể được hiểu bởi tầng Ứng Dụng và được truyền hiệu quả qua mạng.

### Ví dụ
Khi bạn truy cập một trang web bảo mật (HTTPS), tầng Trình Diễn mã hóa dữ liệu của bạn bằng SSL/TLS trước khi truyền tải.

### Dịch vụ của Tầng Trình Diễn
- **Dịch dữ liệu**: Chuyển đổi dữ liệu thành định dạng mà ứng dụng đích có thể hiểu.
- **Mã hóa và giải mã**: Đảm bảo dữ liệu được bảo mật trong quá trình truyền tải.
- **Nén và giải nén**: Giảm kích thước dữ liệu để tăng tốc độ truyền tải.

## Các Giao Thức trong Tầng Phiên và Tầng Trình Diễn

### Application Filing Protocol (AFP)
- Được sử dụng trong mạng Apple để chia sẻ tệp và tài nguyên.
- Ví dụ: AFP cho phép các máy tính Mac chia sẻ tệp qua mạng.

### NetWare Core Protocol (NCP)
- Được sử dụng trong hệ điều hành Novell NetWare để giao tiếp máy khách-máy chủ.
- Ví dụ: Cho phép chia sẻ tệp và máy in trong mạng NetWare.

### Secure Socket Layer (SSL)
- Cung cấp giao tiếp mã hóa cho các giao dịch internet an toàn.
- Ví dụ: Các trang web HTTPS sử dụng SSL để bảo vệ thông tin đăng nhập và dữ liệu truyền tải.

### Remote Procedure Call (RPC)
- Cho phép chương trình thực thi các thủ tục trên hệ thống từ xa như thể chúng đang chạy cục bộ.
- Ví dụ: Windows sử dụng RPC để quản lý dịch vụ mạng.

### Point-to-Point Tunneling Protocol (PPTP)
- Được sử dụng để triển khai mạng riêng ảo (VPN).
- Ví dụ: Nhân viên sử dụng VPN dựa trên PPTP để truy cập tài nguyên công ty từ xa.

### Multipurpose Internet Mail Extensions (MIME)
- Xác định các loại nội dung email, hỗ trợ đính kèm hình ảnh, âm thanh và video.
- Ví dụ: Gmail sử dụng MIME để gửi và nhận email có tệp đính kèm đa phương tiện.
