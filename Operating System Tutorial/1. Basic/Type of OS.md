# Types of Operating Systems

## 1. Batch Operating System
Batch Operating System executes jobs in batches without user intervention. It is used in mainframes where users submit jobs to be processed later.

**Example:** Payroll systems, bank statements processing.

## 2. Time-Sharing Operating System
A Time-Sharing OS allows multiple users to share computer resources simultaneously by giving each process a small time slice.

**Example:** UNIX, Multics.

## 3. Distributed Operating System
A Distributed OS manages multiple computers as a single system, distributing tasks across multiple nodes to improve efficiency.

**Example:** LOCUS, Amoeba.

## 4. Network Operating System
A Network OS provides services over a network and allows communication between connected devices.

**Example:** Microsoft Windows Server, UNIX.

## 5. Real-Time Operating System
A Real-Time OS processes data and executes tasks within a strict time limit, often used in embedded systems.

**Example:** VxWorks, FreeRTOS.

## 6. Mobile Operating System
A Mobile OS is designed for smartphones and tablets, providing an interface and hardware management.

**Example:** Android, iOS.

# Các loại Hệ điều hành

## 1. Hệ điều hành Xử lý theo lô (Batch OS)
Hệ điều hành xử lý hàng loạt thực thi công việc theo từng lô mà không có sự can thiệp của người dùng. Nó thường được sử dụng trên các máy mainframe.

**Ví dụ:** Hệ thống tính lương, xử lý sao kê ngân hàng.

## 2. Hệ điều hành Chia sẻ thời gian (Time-Sharing OS)
Hệ điều hành chia sẻ thời gian cho phép nhiều người dùng sử dụng tài nguyên máy tính cùng lúc bằng cách chia thời gian xử lý thành các khoảng nhỏ.

**Ví dụ:** UNIX, Multics.

## 3. Hệ điều hành Phân tán (Distributed OS)
Hệ điều hành phân tán quản lý nhiều máy tính như một hệ thống duy nhất, phân phối tác vụ giữa các nút để tăng hiệu suất.

**Ví dụ:** LOCUS, Amoeba.

## 4. Hệ điều hành Mạng (Network OS)
Hệ điều hành mạng cung cấp dịch vụ qua mạng và cho phép các thiết bị giao tiếp với nhau.

**Ví dụ:** Microsoft Windows Server, UNIX.

## 5. Hệ điều hành Thời gian thực (Real-Time OS)
Hệ điều hành thời gian thực xử lý dữ liệu và thực thi tác vụ trong khoảng thời gian nghiêm ngặt, thường được sử dụng trong hệ thống nhúng.

**Ví dụ:** VxWorks, FreeRTOS.

## 6. Hệ điều hành Di động (Mobile OS)
Hệ điều hành di động được thiết kế cho điện thoại thông minh và máy tính bảng, cung cấp giao diện và quản lý phần cứng.

**Ví dụ:** Android, iOS.
